# Assignment 2 – SPL Token & NFT (Turbin3 Pre-Builder)

This project is part of the Turbin3 Pre-Builder Assignment 2 focused on Solana SPL Tokens and NFTs using MPL Core.

## Tasks Completed

- Minted a custom SPL Token on Solana
- Minted an NFT using MPL Core
- Implemented a Core Plugin in MPL Core for the NFT
